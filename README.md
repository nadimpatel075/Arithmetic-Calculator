# 🧮 Arithmetic Calculator

A modern, premium-style arithmetic calculator built using **HTML, CSS, and JavaScript**. It features a clean Minimal Luxury interface, scientific calculations, calculation history, theme customization, and more.

## ✨ Features

- **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
- **Scientific Calculator:** Trigonometric functions, logarithms, square roots, powers, and factorials.
- **Calculation History:** View and reuse previous calculations.
- **Theme Toggle:** Switch between dark and light themes.
- **Copy Result:** Copy calculated results to the clipboard.
- **Sound Effects:** Optional interactive button sounds.
- **DEG/RAD Mode:** Switch between degree and radian calculations.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Keyboard Support:** Perform calculations using your keyboard.
- **Local Storage:** Saves calculation history and theme preferences.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Local Storage API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nadimpatel075/Arithmetic-Calculator.git
```

### 2. Open the project folder

```bash
cd Arithmetic-Calculator
```

### 3. Run the calculator

Open `index.html` in your web browser.

No additional installation is required.
